# Stronghold-Luck · 自选商店 + 倍速

给 `D:\Stronghold-Protocol`（明日方舟「卫戍协议：盟约」同人复刻）加三件事：**商店里出什么，由你挑**（自选槽位 / 直购，外加一条「阵营锁」把商店限定在你选的盟约上）；**战斗多快，也由你定**（1×/2×/4×/8×）；**沙盒**（叠策略、解锁布置地块、改技能与属性）。

不改游戏目录里的任何文件。游戏更新了直接覆盖，这个外挂照常用。

---

## 用法

Windows 双击 `start.cmd`，macOS / Linux 跑 `./start.sh`，浏览器会自动打开 `http://127.0.0.1:3000`。

### 游戏装在哪儿，它自己找

外挂不要求游戏在哪个盘。双击 `start.cmd` 之后，它按这个顺序找：

1. `mod.config.json` 里的 `gameRoot`（填过就用它）；
2. 自动探测：外挂旁边的 `Stronghold-Protocol`、当前目录、各盘根与常见的 `Games` / `SteamLibrary` 位置、桌面、下载、文档；
3. 都没找到就问你一句：Windows 上弹一个文件夹选择框，**macOS / Linux 上是在终端里让你输入路径**（那边没有 FolderBrowserDialog，也没有 `start.cmd` 能拖文件夹）。指到游戏文件夹（里面有 `server` 那个）就行，选完写进 `mod.config.json`，以后不再问。

也可以自己指定，三种都行：

- 把游戏文件夹**拖到 `start.cmd` 上**；
- 改 `mod.config.json` 的 `gameRoot`（JSON 里反斜杠写两个：`"E:\\Games\\Stronghold-Protocol"`）；
- 命令行 `node src/launcher.mjs --game "E:\Games\Stronghold-Protocol"`。

**它会认游戏版本。** 不是 0.3.3 时启动时打一行提醒；上游改过锚点的话，面板会整块不出现（见「游戏更新了怎么办」）。

命令行也行：

```
npm start                      # = node src/launcher.mjs
node src/launcher.mjs --game "E:\Games\Stronghold-Protocol"   # 临时指定游戏目录
node src/launcher.mjs --no-pick     # 找不到游戏目录时不弹框，直接报错（给脚本用）
node src/launcher.mjs --port 3001
node src/launcher.mjs --no-open
node src/launcher.mjs --vanilla     # 页面都不注入，等于原版
node src/launcher.mjs --no-log      # 不记录对局（见下）
node src/launcher.mjs --log-dir D:\lucklogs   # 换记录目录
node src/launcher.mjs --speed 4     # 开局倍速（默认 mod.config.json 的 combatSpeed，2 = 游戏原速）
```

关掉：在那个窗口按 Ctrl+C。

**想回到原版**：直接进游戏目录跑 `npm start`，或者 `npm run launch`。这个外挂完全不参与。

### 界面里怎么用

1. 进对局、到休整期，画面右侧有个**「自选」**药丸按钮（可以拖动到别处，位置会记住）。
2. 点开 → 上面是**槽位页签**（槽位 1/2/3 + 装备），中间一行是**模式开关**和**每回合上限**，下面是**当前等级能出现的全部干员/装备**（带阶级、价格，已有的会显示合并进度）。有搜索框和职业筛选。
3. 选一种模式：

   - **放入槽位**（默认）：点某个槽位 → 点某个干员 → 该槽位就变成他；关掉面板，回原版商店栏照常买走。槽位买掉就没了，要再买就照常花 1 块钱刷新。这就是官方的槽位规则。
   - **直购**：点某个干员/装备 → 立刻花钱进手牌。不占槽位、不用刷新，省掉每件 1 块的刷新税。

4. 两种模式**共用一个每回合次数**：默认 3 次，面板那行「每回合上限」随时可改（0 = 不限）。次数用完后卡片会提示，改上限即刻生效。
   - **装备不占这个次数**：放槽位也好、直购也好，装备随便买。次数只算干员（那条额度本来就是给「往场上塞人」定节奏的）。

**看两种样子。** 标题栏右上的**「名字 / 立绘」**切换列表的画法：

- **名字**（默认）：一行一个干员，名字、阶级、价格，列表长的时候一眼扫完。
- **立绘**：一张卡一个干员，立绘按素材原本的 1:2 画满，不会被裁掉。

**面板大小自己定。** 标题栏右上的**「小 / 中 / 大 / 满」**是四个常用尺寸，右下角还有个**拖角**，拽它就能拉成任意大小；两者都记在这个浏览器里。列表太长就把面板拉大。

面板标题栏左边有**「商店 / 沙盒 / 自选位 / 开关」**四个页：商店是上面这些，另外三个见下面各节。屏幕右侧还多了一条**沙盒**小条（在自动买卖条下面），最常用的两个开关在那儿。

### 阵营锁（商店只刷所选盟约的干员）

商店页多了一行**「阵营锁」**。勾开它、再点几条盟约，**商店自动刷新**出的干员就只剩这些盟约的了。想打炎国加灵巧加奥术，就勾这三条，别的一律不出。

**盟约可以勾多条，口径分两种。** 全游戏 266 名干员里有 162 名带两条盟约，所以勾得越多，两种口径的差别越大：

- **包含（并集）**：干员带了所选里**任意一条**就出现。勾 {拉特兰, 迅捷}，能天使 `[拉特兰,迅捷]` 出现，纯拉特兰的也出现。
- **仅限（子集）**：干员的**每一条**盟约都得在你勾的这几条里才出现。同样勾 {拉特兰, 迅捷}，能天使留下，`[拉特兰,维多利亚]` 挡掉（它带着你没勾的维多利亚）。**只勾一条时，仅限就等于「只出纯单盟约的干员」。**

- **一行「当前可选 N 名」告诉你这个组合还买得到几名干员**。这个数受调度中心等级和卡池剩余份数限制，所以同一组盟约在前期和后期不一样。**选成 0 会标红**，那一回合的商店会刷空。
- **只管商店的自动刷新。** 面板里的自选/直购列表**不跟着变窄**，你依旧能挑任意买得起的干员买。自动倒转也照旧。
- **只管你自己那一座。** 三个 AI 队友的商店不受影响。
- **空槽是正常结果**：过滤后没有可出的干员时那个槽就是空的，不会退回全盟约。
- **自选编队的干员也一并过滤**：你在「自选编队」里挑的那几名，如果盟约不过所选与口径，商店也不会再刷他们。
- 装备不受影响（它没有盟约）。
- 设置记在这个浏览器里，进新对局自动带上（和每回合上限、倍速一个做法）。换一组盟约不必等下一局，改完接着刷新就生效。

### 沙盒

外挂的玩具箱。它默认什么都不做，开了才生效；设置记在这个浏览器里（和每回合上限、倍速一样的做法），下次进对局自动带上。

**多选策略。** 游戏自己只让你选一个策略，每个策略有一条永久规则和一个起手目标生命值（20 到 45）。

- 主策略照旧在游戏自己的草稿界面选（那个决定界面显示和风向），**额外的在沙盒页里勾**，勾几个生效几个，列表按起手 LP 从高到低排，主策略排在最前、带金色左边框和「主」标记。
- **起手 LP 取所选里最大的那个**（叠歌利亚就按 45 算）。
- **不设上限**（2026-10-10 起）。重复勾同一个没有意义（勾一次就够，计数器会翻倍的那种毛病不存在）。
- **有 11 个策略的效果只在战斗里跑**（阿米娅、歌利亚、埃芒加德、克莱门莎、大帝、桑葚、休谟斯、卡莱莎、陈、伊奥莱塔·罗素、Touch）：它们在整备期没有任何可看的反馈，但**开战时会真的装进战斗**（外挂在两边都接了这个入口：你自己那场是浏览器跑的，AI 队友那场是服务端跑的）。想确认的话开一局看控制台，会有 `battle-side extra strategies installed: N`。
- **坎诺特的「利滚利」（休整期结束不清空资金）也认额外策略**：它本来是结算规则不是效果，只读主策略，外挂单独接了这条。
- **鸭爵（神秘顾客）当副策略也生效**（2026-10-10 起）。它的换敌效果不是按策略注册的，而是一支全局处理函数，判据读的是「我持不持鸭爵」，所以以前当副策略时整段被跳过。外挂在派发那一层补了这段，调用期间把持鸭爵座位的身份临时遮成鸭爵、跑完还原。它从**第 5 回合**起换敌，且每回合可能一位都不换（游戏自己的参数）。
- 有一个顺序问题已经处理过：**老鲤的「每回合给钱」是直接赋值**（那回合的收入就是它给的数），不是加法。所以它被排到最前面跑，坎诺特的利滚利这类加法才不会被它冲掉。

**解锁布置地块限制。** 勾上之后，**原本地形不允许部署的格子都能放了**；阻隔工事之类被场地装置占掉的格子照旧不能放（那是挡路的东西，不是规则）。

- **近战也能上高台**。游戏本来就有这个机制，靠的是干员特性写没写「可以放置于远程位」（歌蕾蒂娅、崖心、见行者就靠它上高台），外挂做的是把这条放到所有干员身上，等于人人一双舞鞋。
- 放上去之后**不会被撤回**：回合开始、拿到机变卡、改地形的时候游戏会重算一次合法性，走的是同一张放宽后的图，所以站得住。
- **把勾去掉**，站不住的东西会被拉回整备区（这是游戏自己的行为，没有绕过它）。
- 旁边那个**「部署上限」**留空是游戏自己的 8；填个数就是它的下限（召唤物本来就不占上限）。

**单位（技能 / 技力 / 属性）。** 沙盒页最下面一栏：改某一（或某些）干员的携带技能、技能消耗、初始技力和任意一项属性。**留空 = 不改**，所以默认什么都不发生。

- **作用目标**三档。**这一名**只改你在上面点中的那一名（也能换它的携带技能）；**我的全部**改你场上每一名干员；**全场**连三个 AI 队友的场次一起改。
  - 为什么分三档：**你自己那场战斗是浏览器在跑，AI 队友的场次是服务端在跑**，两边各自从 `chess.json` 解出属性，所以「改我自己」和「改全场」落的是不同的补丁。前两档只动浏览器这一侧，第三档才连服务端一起打。
- **携带技能**只能换成这名干员自己有的那几个（就是「干员调配」里能选的那些）。换成**没有专属实现**的技能会退化成通用技能，能放，只是没手写的那一套效果；**补位干员和自选编队的技能不跟着改**。这一栏只对「这一名」有意义（每名干员的技能表不一样），选另两档时它会收起来。
- **技力**：技能消耗、初始技力。这一栏**盖得过干员自己的实现**（很多干员的技能消耗是手写在技能里的，外挂改的是运行时那一层，所以手写的也压得住）。
- **属性**填的是**绝对值**（留空 = 不改）；**总倍率**乘在所有属性上。**费用和再部署不跟倍率走**，那两项翻倍是给整备期添堵，不是变强。逐项填了的那些**以填的值为准**，倍率只作用在没填的上面。
- **作用域**：技能/属性是按**干员**算的（同一个干员的复数张卡一起吃），不是按某一颗棋子。
- **对局中途改不了已经落地的东西**：属性是开战时从定义里拷进单位的，所以改完要**下一场**（本回合的战斗已经在打了）才看得到。改完可以直接按「准备就绪」验。
- **认不出的地方**：游戏自己的**详情卡「基础值」一栏读的是另一份数据，不会跟着动**；战斗里的实时数值是对的。
- 整套配置记在这个浏览器里。**「钉住」勾着**（默认）才会自动带进下一局。

### 自选干员（自选编队）

游戏 0.2.0 起有**自选编队**：在「干员调配 → 自选编队」里为 5 阶、6 阶各挑两名干员，对局里它们就进你自己商店的卡池。面板认这些干员：

- 它们**混在普通干员里列出来**，带一个绿色的**「自选」**标记，名字和立绘是你在编队里挑的那名干员本身，排在最前面。
- 每个自选槽位有**自己的调度中心门槛**（5 阶的要 Lv.5，6 阶的要 Lv.6，和游戏里一样），**等级没到的会灰着列出来**，点它只会告诉你还差几级，不会消失不见。
- 某一名自选干员本局被禁（它所属的盟约全被关掉）时不会出现在列表里，和游戏自己的商店一致。

价格两种模式一样，都走游戏自己的 `buy` 判定，也照常吃阵营/驻防的价格折扣。

### 自选位（给自选干员配盟约 / 特质 / 数值）

面板第三个页签。背景：自选干员本来只带一条按**势力**推出来的盟约（86 名可选干员里 **53 名**的推导结果是**协防干员**，而**阿戈尔、谢拉格**两个赛季盟约对自选干员根本不可达），并且**一条特质都没有**。这一页把三样都交给你，而且**按位子生效**（谁坐在那个位子上谁就吃这一套，换人不变）：

- **盟约**：给这个位子勾盟约，可多选。三档模式：**跟随干员**（默认，不动干员本来那条）、**替换**（只算你勾的，一个都不勾 = 这个位子不再算任何盟约，协防干员那条也会掉）、**叠加**（在干员本来那条之上再加）。没勾过盟约的位子停在「跟随干员」，所以只加一条特质不会顺手把它的盟约清掉；点任意一条盟约就自动转成「替换」。阿戈尔、谢拉格现在勾得出来。
  - **少点几下**：`全选` 把能生效的盟约一次全勾上（22 条），`清空` 全去掉，`用默认` 补上「新位子默认」那几条。另外**按住鼠标往下扫过一片就能连着勾**（或者连着取消），不用一条条点。
  - **`绝技` 点不动**，是故意的：它数的不是成员，而是场上**所有精锐棋子**的数量，效果也落在每个精锐身上，所以挂给哪一名干员都不会有任何变化，游戏里 258 枚棋子也没有一枚带它。它在下拉里灰掉划掉，旁边会写原因。
  - **`新位子默认带上`**：在「自造位子」那一栏里给自己定一套默认，**盟约**和**特质**各一行。盟约那行初始是**调和**（调和成员在场时享受**每一条核心盟约**的效果，是让自选干员变成核心成员最省事的一条）；特质那行初始是空的，你自己挑（用的是同一个分组选择器）。新加的自造位子会自动带上这两套，任何位子也可以点 `用默认` 补上（只加不减）。
- **携带技能**：每个位子一行下拉，选这一名在这个位子上带哪个技能。**默认是最后一个**（三技能），和游戏自己的自选编队一致；想让他带二技能就把下拉改成 S2。原型干员的技能是数据里定死的，下拉灰着并写明原因。改完之后服务端会**按新技能重新合成这个位子的记录**，连精锐形态和这一座的作战输入一起跟着换。
- **模组**：同样一行下拉，`不带模组` 在最前。只列**精锐形态**能装的（`ISW-` / `SO-` / `RA-` 那几个只在别的模式里生效的模组不列），并带上模组自己的名字和编号（如「Mon2tr（PHY-X）」）。模组本来就只在精锐形态生效，所以非精锐的那一颗带上了也不激活，和普通棋子一样。
- **特质**：「＋ 加特质」从 `data/garrisons.json` 里挑，带搜索。就是别的干员身上那套「获得时叠层」「售出时给资金」「购买价格为 1」「和别的棋子配合」等等，作战内的 60 条也在里面。
  - **按触发时机分组**：获得 / 售出 / 价格 / 刷新 / 休整期开始 / 休整期结束 / 作战，各组一个标题。
  - **每条标明来自哪张卡**：列表每行下面写着「来自惊蛰、角峰…」，搜索也能按棋子名搜（想给谁的效果就直接搜那名干员）。
  - 只列**普通形态**那一条（`_a`）：精锐形态自动换成带精锐数值的那一条（`_b`），和普通棋子的 `_a`/`_b` 记录一模一样，不用你选两次。悬停能看到普通与精锐两套数值。
- **数值**：点「数值」，逐条列出这条效果**真正读的那些键**（从记录里读出来的，不是猜的），填你自己的数，留空 = 用原值。

两条必须知道的边界：

- **特质的数值是每个位子各一份**（外挂给那个位子造了一份独立记录，原记录一个字节不动）；**盟约的数值整场共用一条**。原因是数据本身：盟约的战斗效果在游戏里是**按 id 手写**的，一条盟约只有一个记录，所以同一条盟约的改动会落在场上**每一个**带它的干员身上，两个位子改同一条时以先勾的那个为准（面板里写着这句话）。只想让某一个位子更能打、又不想碰别人，用「沙盒 → 单位」那一栏（它按棋子改属性，自造位子的棋子 id 就是位子本身）。
- 勾到**本局禁用**的盟约、且这个位子的盟约**全**被禁时，它会像游戏自己那样从商店里消失（官方行为）。

### 自造位子（位子加量、阶位随便挑）

游戏只有四个自选位（5 阶两个、6 阶两个），而且写死在它的数据里。「自选位」页底下可以**自己加位子**（最多 12 个），每个位子自己选**阶位 1 到 6**、自己挑放谁：

- 阶位决定**价格、调度中心门槛、库存份数**（1 阶位 Lv.1 就能刷出来、12 份），**能放的干员不变**，还是那 88 名（80 名 6★ + 8 名 4★ 预备干员）。自选干员的「练度形态」数据只有这两档，1/2/3/5 星在游戏里没有底料，联动干员更是一个字节都没有。所以这一层只放开**位子的阶**，不放开**人的池子**。
- 自造位子和内置位子吃**同一套盟约 / 特质 / 数值**。
- 加出来的位子出现在面板的候选列表、你自己商店和随机获得里，和游戏自带的自选干员一样。

### 倍速

屏幕右侧还有一条**倍速**条（`1× 2× 4× 8×`，同样可以拖动，位置会记住）。点一下就换，**战斗打到一半也能换**。

- `2×` 是游戏自己的原速；`1×` 是放慢（想看细节时用）；`4×`、`8×` 是加速。
- 选中的那个按钮点亮的是**服务端此刻的倍速**，不是浏览器的记忆。改过之后，之后每一局都从这个倍速开始（服务端记着），重启启动器才回到 `mod.config.json` 的值。
- 换倍速只改「游戏里的 1 秒 = 现实的几秒」，**模拟本身一步一步照跑**，所以同一场战斗在任何倍速下结果一样，不会因为加速少打几个 tick、改掉暴击或漏怪。

**过场等待也跟倍速**（单人局）。战斗结束、结算、回合开始这三段是游戏写死的现实秒数（1.5 s + 3 s + 2 s），它们读的是另一个旋钮，本来不跟倍速走，所以以前 8× 时每回合仍有 6.5 秒干等。现在有一条外挂把这三个数按倍速缩短（8× = 四分之一），倍速条上会显示 `过场 ×0.25`。只缩短这三段；**battle 结果宽限**那类靠等才等得到正确结果的时间一律不动，同盟房间（有两个以上真人）也不动，免得砍到别人的决策时间。

**战斗的时间上限跟着倍速走，不用调。** 上限是**游戏秒**（普通回合 `maxPlayTime × 2`，例如 90 游戏秒），所以 2× 时是 45 现实秒、8× 是 11 秒，任何倍速下**场上发生的事情一模一样**：出怪时刻表、boss 技能节奏、漏怪扣的生命、boss 超时后每秒流失的生命，全都按游戏秒算。打 boss 时那个「生命流失」也是按游戏时钟算的纯函数，倍速只决定它多快到来，不决定它掉多少。

唯一会失真的情况是**机器跟不上**：现实时间跑得比模拟快时，服务端每 33 ms 最多补 `max(8, 4×倍速)` 个 tick，超出就把这一份时间丢掉（避免滚雪球），于是那一场会落后于墙上时钟。8× 时有 4 倍余量，正常机器碰不到；真卡住了浏览器会把落下的 tick 全补回来（它不丢 tick），服务端那侧另有接管兜底。

### 自动买卖（倒转）

屏幕右侧再往下一条**自动买卖**条（在倍速条正下方）。它替你把「经济倒转」那一串操作跑掉：**买到目标卡 → 把它掉出来的「盟约之币」装备掉（回收资金）→ 再把这张卡卖回去**，一轮接一轮。

- **目标是一张勾选表，不是单选。** 点条上的「目标 N/M」展开，勾几张就倒几张：**同一个循环里，哪张勾着的卡此刻在台面上就买哪张**。表里只列本局协议里真的有的卡：本局禁用的盟约、以及游戏藏起来（`visible:false`，商店和奖励都不会给）的卡，比如红豆、蜜蜡，都不会出现。
- **两套刷法**，条右边会写出这一批跑的是哪一套。分档看**奇迹满没满一百层**；手里已经攥着免费刷新次数时，这一批也按免费那一套走（那些次数是确定免费的）。
  - **免费刷**（奇迹 ≥ 100，或有免费次数）：滚商店不花钱，所以勾了就抓。只有「下期」那四张例外，它们的钱落到下个休整期，免费刷时没意义。滚够 40 次还不见目标就收手，不会空转。
  - **收费刷**（奇迹 < 100）：每一滚都在掏钱，所以只抓**经济牌**，也就是能把这一滚的钱挣回来或者省下来的那些。表里标着「非经济」的（焰尾就是，它落的是干员不是钱）平时不抓，**但它买进卖出不亏的时候照样抓**：远见的 −1 是永久的，原价两块的压到一块，卖掉还回一块，这一圈不花钱，就跟至简一样白转一次、白跑一次买卖计数。没碰到能抓的就接着刷，滚到没钱为止。
- **三类卡**（表里按类别分组，每行末尾标着类别）：
  - **当期**：收益当期兑现，有诗怀雅（掉盟约之币）、普罗旺斯和德克萨斯（给免费刷新）、焰尾（白嫖干员）、至简（买价 1）。默认勾上。
  - **下期**：收益落到**下个休整期**，有能天使、新约能天使（获得时给钱）、泥岩、格雷伊（售出时给钱）。免费刷时自动跳过，收费刷时抓。默认勾上。
  - **道具**：耶拉（不融冰）、洛洛（定制品）、卡涅利安（迅捷作战粮）、缪尔赛思（变形同构体）。「回收」那一步只认盟约之币，这些道具收不了，所以**默认不勾**。
- **每行的等级门**：这个等级买不起的卡是灰的、点不动，行尾写「Lv.N」。灰着的那一行显示成未勾选（勾选状态留在浏览器里），调度中心升到那一级之后重新生效。
- 一张都不勾时「启动」是锁住的，空勾选发不出有意义的批次。
- **买到手有两种方式，条上左边那个下拉选。**
  - **商店**（默认）：用游戏自己的刷新与购买。商店里没有目标卡时替你按**刷新**（「刷新」勾上，见下），出现了就买它，买完卖掉。这条路**一个模组功能都没用到**，所以**总开关全关也照跑**，就是正常游玩里那个「快一点、买卖自动」的样子。
  - **直购**：模组直接把它塞进手牌，不进商店、不占槽位、不用刷。它属于「自选商店」那一组，**那一组的总开关关掉之后就会被拒**（条上会写 `停：direct-off`）。留着它是因为有些场合商店根本出不了目标卡。
- **「刷新」勾上就替你滚商店**（只走商店那条路）。滚到什么时候停，看上面那两套刷法。远见的 −1 价格也是游戏自己算的，这里不插手。
- **必须手动点「启动」**，不会自己跑。跑起来之后**同一个按钮就是「停止」**（就这一个键），再点一下即停；它自己停下来之后按钮直接回到「启动」，不用先点一下停。
- 这张表也可以**拖动**（和倍速条一样，位置记在这个浏览器里），嫌它挡屏幕就拖走。
- 「每次请求跑几轮」是批量大小，服务端跑完一批浏览器就接着下一批，所以**不用你点**；**你准备了（或商店关了）它自己停**。
- 「币」勾上就把掉出来的盟约之币装备回收；「身份牌」勾上会在资金有余时买「随身身份牌」装上（金币换层数）。
- 它**不占**上面那条「每回合上限」。那个额度只约束你手动点的自选／直购。
- 只碰它自己这一轮买进的卡：**你手里的干员和币，它一张都不卖**。
- 遇到「再买一张就会合成精锐」时会**停手**（勾了别的卡就换那张继续），不把你已有的干员吞掉。
- 条右边实时显示这一批的结果：`免费刷/收费刷 · 轮数 · 刷 N · 金 ± · 层 +`，停下时附原因。

### 总开关（把修改功能整块关掉）

面板标题栏的**「开关」**页。一格一组，把哪一组关掉，**那一组就整个不存在**：服务端不再接受它的设置，**还会把已经生效的部分撤回去**。已经配好的自选位连同它的库存一起收回，叠上的策略清空，解锁的地块拉回来，单位规则复位。面板不发新设置**不算数**。关着的时候页签上会亮一个记号，免得「怎么什么都不管用了」找不到原因。

**关掉之后，面板和游戏界面里也不会再出现那一组。** 自造位子会从面板那一页和游戏自己的「自选编队」里一起消失；被关掉那一节的控件换成一行说明。这一组本来就是「整个不存在」的意思，早先的版本只做了服务端那一半，画面里会留一个点不动的空壳。

分组是七格：自选商店（含直购与每回合额度）、沙盒·策略叠加、沙盒·地块解锁、沙盒·单位、自选位·盟约/特质/数值、自选位·自造位子、阵营锁。

- 页顶有**「全部关掉 / 全部打开」**两个键。全关之后剩下的就是**原版规则 + 倍速 + 自动买卖**：倍速和自动买卖**不属于任何一组**，怎么关都在。
- **一局里改也生效**，不用退到大厅。开关记在这个浏览器里，每局开始时推一次给服务端（服务端那边是进程级的，重启启动器才回到全开）。
- **两个页面同时开着的时候要注意**：开关也是「本机记住、开局推一次」，所以另一台开着旧设置的页面进新对局时，会把它那边的设置推上去。

### 联机 / 公网：房间里其他人也能用吗

**能。** 这个外挂挡在游戏服务器前面：游戏本体起在一个随机端口，外挂的前台服务占了配置端口（默认 3000）。朋友连的是**外挂这个端口**，所以谁从它进来，加载到的页面就带面板，服务端补丁也是**整个房间生效**的，不是只对自己那一座。

让朋友连上你的机器有三条路，三条都能用：

- **同一局域网**：直接连你的局域网 IP。
- **VPN**（Tailscale / ZeroTier）：等于把大家拉进一个虚拟局域网，连你的 VPN IP。
- **内网穿透**（frp / cloudflared / ngrok）：把本机端口经一台中转暴露成一个公网地址，朋友连那个地址。

这三条是同一个问题的不同解法，挑一条就行，不用叠着开。

一个前提：**外挂默认只听 `127.0.0.1`**（只允许本机）。穿透工具跑在你本机、连的也是本机端口，所以穿透这条路不用改；走局域网 / VPN 的朋友要连你机器的 IP，就得让外挂听全：

```
node src/launcher.mjs --host 0.0.0.0
```

也可以把 `mod.config.json` 的 `host` 改成 `0.0.0.0`，但那会让**同一网络里任何人都能连进来**，自己掂量。

### 手机上玩：手机当客户端，电脑开着服

外挂不需要手机版，因为它本来就挡在游戏服务器前面：**谁从它这个端口进来，加载到的页面就带面板**。所以手机浏览器直接连电脑就行。

1. 电脑上加 `--host 0.0.0.0` 启动：`node src/launcher.mjs --host 0.0.0.0`（或把 `mod.config.json` 的 `host` 改成 `0.0.0.0`）。默认只听 `127.0.0.1`，手机连不上就是卡在这里。
2. 放行 Windows 防火墙的入站（第一次启动时弹的窗里勾「专用网络」）。
3. 手机与电脑同一个 Wi-Fi，横屏打开 `http://<电脑的局域网 IP>:3000`。

面板会自己认出小屏和触屏（认到就往 `<html>` 上挂 `spmod-touch`），行高、勾选框、按钮、槽位页签一律放大到手指点得准；面板张开时「倍速 / 自动买卖 / 沙盒」三条悬浮条先让位，关上面板就回来。**面板的字号跟着游戏的「设置 → 文字大小」走**，所以手机上把那一项调成「大」或「特大」，游戏和面板会一起变清楚。

## 安卓版（APK）

`android/` 是一个把游戏和外挂一起装进手机的壳：内嵌 Node（libnode，JNA 直调 `node::Start`）加一个 WebView，装完打开就是带面板的游戏，不用电脑。

**它不含游戏本体。** APK 里带的是游戏代码（上游的 lite 包）和外挂本体；美术、音频、字体（约 560 MB）在**第一次启动时**从上游的完整包里取出来，所以第一次打开要联网、要等几分钟，之后就离线可玩。

- 要求 Android 7.0 及以上、arm64。
- 和朋友联机：手机开着游戏，同一 Wi-Fi 下他们打开 `http://<手机的局域网 IP>:3000`。
- 出包：仓库的 Actions 里跑一次 `Build APK`（手动触发，或在 `android/` 下有 push 时自动跑），产物在 Actions 的 artifacts；带 `release_tag` 触发就直接挂到对应的 Release 上。

不想在本地装 Android SDK 就用云端出包，脚本做两件事：`scripts/stage-assets.sh` 把上游 lite 包与本仓库的 `src/`、`public/` 铺进 `app/src/main/assets/`；`scripts/fetch-libnode.sh` 取 libnode.so（60 MB，不入库）并从 Android NDK 里复制 `libc++_shared.so`。少了后者，APK 一启动就 `dlopen failed`，界面是一片白。

**已在安卓模拟器上实测跑通**（雷电 9，Android 9，x86_64；2026-10-15 晚，v0.1.4 之前的那版 APK）。装上就能进：Node 真起来了，外挂的挂点全部落上，游戏服务器在 `127.0.0.1:3000` 应答，WebView 里从标题页走到休整期，面板可用（当场直购了一名干员，资金扣了、服务端的操作记录里也记下了）。跑通的这套流程包括手机上那个视口下面板的尺寸与位置。

真机的触屏手感和性能还没试过。出问题的话，应用界面本身就是日志：Node 的 stdout / stderr 被接进了那个日志框，把那几行发出来就能定位。想自己复现这套验证，看「自检」一节末尾。

## 它到底改了什么

**改三件事。**

- 改的：商店槽位的内容不再随机，由你指定；另外多一条**直购**路径，不经过槽位直接进手牌，这两条路共用一个**每回合次数上限**（默认 3，面板可调）；**阵营锁**（可选，打开后商店的自动刷新只出所选盟约的干员）；再就是**倍速**（1×/2×/4×/8×，战斗里也能换）。
- 没改的：调度中心等级限制（只有 ≤ 等级的干员可选）、卡池剩余份数、本局禁用的盟约/干员、资金、价格、刷新价、槽位数量、合并规则、部署上限、敌方数值、boss 血池、赏金与地图的随机。直接买和放槽位都走游戏自己的 `buy` 判定，价格照常吃阵营/驻防的折扣。倍速走的是游戏自己就有的 `gameSpeed`，模拟一个 tick 都不动。
- 沙盒是**另一档**：地块解锁、策略叠加和「单位」那一栏会真的动规则与数值，**敌方不在其中**（只有你和 AI 队友的干员）。它是「我可以不用，但我不能没有」，默认什么都不做。

所以不开沙盒时它是"运气无限好"，不是"数值修改"。要凑三张同名干员合成精锐，把三个槽位都点成他然后一起买走就行；嫌一件件买麻烦就切「直购」。

## 原理（想改的话看这段）

```
start.cmd
src/launcher.mjs       起两个东西：游戏自己的服务器（只在 127.0.0.1 的随机端口）+ 一个前台 HTTP 服务
src/find-game.mjs      游戏不在默认位置时，按一串常见路径去认（认 server/index.js）
src/pick-game.mjs      都认不到就弹文件夹选择框，选中路径经临时文件回传（绕开控制台编码）
src/server-patch.mjs   进程内给游戏打三处补丁
public/overlay.js      浏览器里的面板（由前台服务注入到 index.html）
public/overlay.css     面板样式（复用游戏自己的设计变量）
public/unit-rules.js   沙盒「单位」那一栏的规则本体：服务端和浏览器都 import 这一份，两边算出来的 def 一模一样
test/                  三层自检
```

**前台服务只做两件事**：`/mod/*` 走外挂自己的文件；`/` 和 `/index.html` 的响应里塞一行 `<script>` 和一个 `<link>`。其余请求、以及 WebSocket 升级，原样透传给游戏服务器。

**服务端补丁**（`server-patch.mjs`，改的都是活对象，不碰游戏目录）：

| 位置 | 做什么 |
|---|---|
| `shared/protocol.js` 的 `C2S` | 注册十个新意图 `g.modPick` / `g.modBuy` / `g.modConfig` / `g.modSpeed` / `g.modAuto` / `g.modBands` / `g.modPlace` / `g.modUnit` / `g.modShopFilter` / `g.modDiy` / `g.modEnable`（这张表没冻结，服务端和浏览器的校验都是实时查表） |
| `Match.prototype.handle` | 在游戏的 `case` 分发**之前**截住这些意图（游戏的 `GAME_TYPES` 是加载时的快照，绕开它），顺带把每条 `g.*` 记进日志 |
| `PlayerState.prototype.privateView` | 往 `shop.modPickable` 里塞一份"你此刻能选什么"（普通干员一份 `chess`，本局的自选干员单独一份 `diy`）和本回合的额度（服务端算的，和它的判定同源），并在 `modSpeed` / `modAuto` 里报出本局实际倍速和上一批自动倒转的结果 |
| 新增 `PlayerState.prototype.modPickSlot` | 把某个未售出的槽位内容换成你指定的干员/装备 |
| 新增 `PlayerState.prototype.modBuyDirect` | 直购：照 `buy()` 的前半段查资金/手牌/卡池/等级，然后把干员或装备直接进手牌。自选编队的干员走游戏自己的那条支线：`ps.gd.chess(id)` 是**本人视角**的合成记录（带 `diyFor`），份数从这名玩家自己的 `diyStock` 里取，门槛用槽位自己的 `shopLevel` |
| `Match.prototype.start` | 每局开始时把记住的倍速写回 `gameSpeed`，所以倍速跨局保留 |
| `Match.prototype.scaled` | 过场等待：游戏那三段固定等待读的是 `timerScale` 而不是 `gameSpeed`，所以倍速动不了它们。这里把**恰好等于** `DELAYS.COMBAT_END` / `SETTLE` / `ROUND_START`（1500 / 3000 / 2000 ms）的那几个值按 `倍速 ÷ 2` 缩短，别的 `scaled` 调用一律不碰（boss 结果宽限那类时间是等正确结果用的）；只在 `soloUntimed` 的单人局生效 |
| `EffectDispatcher.prototype.dispatch` | 沙盒的额外策略：每段策略的效果就是注册在 `band:<id>` 下的一段处理函数，游戏每次派发只按唯一的 `ps.bandId` 取一段。这里在原有的那一次之后，把额外策略各自的 handler 也用**它自己的 source** 再各调一次（source 只影响提示文案）。**鸭爵**是个例外：它的换敌效果注册在全局键 `global:bands_ducklord` 下（不是 `band:`），判据读各座位实时的 `bandId`，所以额外策略里看不见它。同一个包装里对 `onBattleStart` 单独补跑这一段：调用期间把持鸭爵座位的 `bandId` 遮成鸭爵、跑完还原；主策略已经是鸭爵时跳过（原本那一次对每个座位都已成立） |
| `PlayerState.prototype._rollChessSlot` | 阵营锁：商店抽牌走 `SharedPool.roll(rng, { maxTier, extra })`，它本来就收一个 `filter`（游戏自己的盟约抽牌用的就是它）。这里把原方法那三行重写一遍、把所选盟约按口径（并集 / 子集）折进 `filter`。`extra`（本座位的自选编队）走同一套过滤；过滤后没得可出就返回 `null`，`rollShop` 本来就允许空槽。只有 `ps.modShopFilter` 打开的座位有这层，AI 队友天然 no-op |
| `Match.prototype._applyBand` | 起手 LP：它是唯一设 `ps.lp` 的地方，多选时改成取所选里最大的 |
| `Match.prototype.deployMapFor` | 地块解锁：判定链是「图块 legend → buildDeployMap → canPlace → PlayerState._legal」，而撤回那一步（`_evictIllegal`）走的也是 `_legal`。所以只放宽这一张图就够，不需要碰判定函数。被装置占掉的格子照旧排除，高台照旧只收远程 |
| `PlayerState.prototype.deployCap` | 部署上限：在游戏自己的数上取一个下限（`get deployCap()` 是从 `PlayerBasics` 继承来的，用 `Object.defineProperty` 盖一层） |
| `DataSource.prototype.getChess` | 沙盒「单位」的属性：属性不在战斗 spec 里，每一边各自从 `chess.json` 通过这一个方法解出来，所以包这一个方法就够（`_makeAlly` 和 `content/index.js` 的 `swapDef` 都读它）。改的是返回值，DataSource 自己那份缓存一个字节都不动（没用上就从 `public/unit-rules.js` 的 memo 里取回原对象，指针不变，`syncUnitLoadout` 的换 def 判定不会被骗到） |
| `SkillRuntime.prototype.reset` | 沙盒「单位」的技力：干员的技能消耗很多是手写在 kit 的 `SkillSpec` 里的，那个**压得过 def**，所以只改 def 会被静默忽略。运行时这一层是最后拍板的地方，所以在这里设 `baseSpCost` / `initSp` 才压得住手写的那份 |
| `PlayerState.prototype.battleInput` | 沙盒「单位」的换技能：改的是这名座位上场的 `skillIndex`，它本来就在 battle spec 里，所以浏览器那一场自然跟着走。只认这台浏览器自己的那个座位（`playerId` 对得上才动），补位和自选编队的不碰 |

浏览器那一半（`public/overlay.js` 的 `patchSimUnits`）把 `DataSource.getChess` 和 `SkillRuntime.reset` 用同一份 `public/unit-rules.js` 打在自己这份 sim 上：**你自己那场战斗是这个标签页跑的**，光改服务端对它是无效的。而「全场」才需要服务端那一半（AI 队友的场次跑在服务端），所以服务端只在 `scope === 'all'` 时才接管，前两档它一动不动。

倍速落地在 `applyGameSpeed`（`src/server-patch.mjs`）：改的是 `Match.gameSpeed`，也就是游戏自己那个 `opts.combatSpeed`。服务端跑的场次（bot、托管接管的场次）每次 pump 都读它，之后开的场次在 `b.start.speed` 里带上它，所有期限和放行时间也都按它算。已经开打的那场要手动收尾两处：把 `startAt` 重算，让它的游戏时钟停在原地不跳（`_fieldElapsed` 是 `((now − startAt) / 1000) × gameSpeed`）；把浏览器那场的结算期限按"还剩多少游戏时间 ÷ 新倍速"重新武装，否则调慢以后旧期限会先到，服务器会把玩家还在看的战斗抢走。浏览器这边（`public/overlay.js` 的 `applySpeed`）把每场本地战斗的 `entry.speed` 换掉、`t0` 同步挪，让 `targetTick` 正好等于当前 tick；渲染引擎的插值速率用 `__SP_VIEW__.raw.setLocalFeed` 就地改，不重进战斗。

**浏览器那边**不替换游戏的任何组件：面板模块直接 `import` 游戏自己的单例（`/js/store.js`、`/js/net.js`、`/js/data.js`、`/js/ui/assetUrls.js`、`/js/ui/gameLogic.js`）来读状态、发请求、取立绘。

补丁里的锚点要是被上游改没了，启动时会打印 `anchors not found`，游戏照常跑，面板自动隐藏（它靠 `shop.modPickable` 是否存在来判断服务端有没有被打补丁）。

## 对局记录

启动器默认把整局记进 `logs/session-<时间>.jsonl`，一行一个事件（`--no-log` 关掉，`--log-dir <dir>` 换目录）。**真人和 AI 座位都记**，这是给"之后优化游戏 AI"取数用的。

事件种类：

| `k` | 什么时候 | 记了什么 |
|---|---|---|
| `start` | 第 1 回合 | 模式/难度/地图/开局三个特殊敌人/boss 回合，以及整场 15 回合的类型与敌人排期 |
| `round` | 每回合开始 | 本回合来敌计划（发起时刻、敌人、数量、上下路、精锐/boss、赏金标记），加每个座位的一行摘要 |
| `prep` | 每回合休整开始 | **真人**的完整 `privateView`（手牌、场上站位、商店、羁绊、可见来敌等） |
| `act` | 每次动作 | 谁（真人/AI）、哪个动作、参数、成功与否、前后状态摘要、是否空转 |
| `intent` | 真人发意图时 | 原始 `g.*` 请求（细；覆盖没有对应动作的那些，以及被拦下的） |
| `combat` | 每次战斗后 | 每个座位的击杀/漏怪/完美 |
| `settle` | 每回合结算 | 每个座位的 LP 前后、掉血、漏怪、是否被淘汰 |
| `end` | 对局结束 | 胜负与最终名次 |

**无效操作怎么标**：每条 `act` 都带 `ok`（失败另有 `err`/`detail`，比如钱不够、槽位已售、次数用完）和一个 `noop` 标志。`noop:true` 表示动作被接受了但没改变任何你能感觉到的东西（重复点同一个干员、把单位拖到原地）。误点、被拒、空转三者分得开。

**记不到的**：纯客户端的点击不发到服务器，日志里没有。点禁用按钮、开关面板、点开敌人属性看，这些记不到。"你看了敌人属性"这个动作本身没有记录，只能靠每回合 `nextEnemies` 的数据侧面反映。

托管（`g.autoplay`）时真人座由 AI 代打，这一行 `ai` 仍是 false，要看同行的 `controlled` 字段。

日志写在外挂目录的 `logs/` 下，游戏目录照样一个字节都不动。

## 游戏更新了怎么办

**这个游戏不会自动更新，也没有版本检查。** 它联网只做一件事：`tools/build-data.mjs`、`tools/fetch-assets.mjs` 去 `raw.githubusercontent.com` 拉**游戏素材和数据表**（跟代码仓库本身无关）。所以更新完全靠你自己去 GitHub 看：

- 仓库：`https://github.com/sganggs/Stronghold-Protocol`（Releases 里的整合包 / 或者你自己 `git pull`）
- 本地这份是 **0.3.3**，`package.json` 里的 `version` 就是当前版本号。

**更新之后**：把游戏目录换掉（或 pull），然后**重新双击 `start.cmd`** 就行。绝大多数情况下外挂不需要任何改动，因为它一个字节都没写进游戏目录。只有在控制台出现 `anchors not found` 时才需要改 `src/server-patch.mjs`：它会告诉你是哪个锚点没了。

**但「没有报错」不等于「还在起作用」。** 0.2.6 → 0.3.0 就踩过一次：游戏把 `Battle` 构造里那句 `this._safe(() => installContent(…), 'installContent')` 改成了直接调用 `installContent(…)`，标签没了，外挂挂在这个标签上的两个东西（沙盒的**战斗侧策略**、自选位的**战斗内数值**）就一起静默失效了。锚点检查看不出来（`Battle.prototype._safe` 还在），控制台也一句都不说。所以更新之后除了看 `anchors not found`，还要**跑一遍自检**（下面那一节）。这次两处都换成挂在 `contentMode` / `contentFault` 这两个属性访问上（见 `public/slot-rules.js` 的 `patchContentSeam`），它们正好卡在内容安装的前后。

顺带一提，0.3.0 加了**插件系统**（数据 / 外观 / 界面插件，`plugins/` 目录，房间顶部有「原版 / 插件」面板）。这一份外挂没有改用它：插件能改的数值、经济、波次和素材，跟这里要的「改手柄而不是改内容」不是一回事（自选商店要读玩家当下的手牌与卡池、倍速要动 `Match.gameSpeed`、沙盒要换战斗逻辑），而且插件的沙盒不提供这些接口。两套可以并存：不开插件时房间就是原版玩法，外挂照常工作。

### 安卓壳怎么验（不用真机）

用安卓模拟器，雷电 9 这类都行。要点与坑：

- **模拟器默认没有 root**，往 `/data/data/<包名>` 里塞文件要用到。雷电：`ldconsole modify --index 0 --root 1`，然后重启模拟器（`quit` + `launch`），之后 `adb root` 和 `su` 都在。
- **别等它自己下那 560 MB**（走镜像实测约 0.3 MB/s，半小时以上）。APK 只从上游完整包里取 `public/assets`、`public/fonts`、`data/local-assets.json` 三样，而这三样本机的游戏目录里就有。推过去再补一个标记文件，首启就直接跳到启动 Node：
  ```
  adb root
  adb push <游戏目录>/public/assets  /data/data/com.strongholdluck.android/files/game/public/
  adb push <游戏目录>/public/fonts   /data/data/com.strongholdluck.android/files/game/public/
  adb push <游戏目录>/data/local-assets.json /data/data/com.strongholdluck.android/files/game/data/
  adb shell "echo -n 0.3.3 > /data/data/com.strongholdluck.android/files/game/.assets-ready"
  adb shell "chown -R 10051:10051 /data/data/com.strongholdluck.android/files && restorecon -R /data/data/com.strongholdluck.android/files"
  ```
  （`10051` 是应用的 uid（`u0_a51`），核一下用 `adb shell pm list packages -U | grep strongholdluck`。`.code-ready` 由应用自己写。）
- **Git Bash 里先 `export MSYS_NO_PATHCONV=1`**：不然 `/data/...` 会被改写成 `C:/Program Files/Git/data/...`，`adb push` 会卡在那儿什么也不传（看起来像模拟器磁盘慢，其实一个字节都没发）。
- 想不碰鼠标把游戏点进对局：APK 里 WebView 调试是开着的，`adb forward tcp:9222 localabstract:webview_devtools_remote_<pid>` 之后可以直接用 CDP 在页面里求值、点按钮。另外 `adb forward tcp:3000 tcp:3000` 能把模拟器里那份游戏直接给电脑浏览器打开看。

## 已知边界

- 面板只在休整期可用（跟官方商店一致），准备就绪后不能改。**倍速条和沙盒条不一样，整局都在**（战斗里也能切）。
- 沙盒里的策略是**每局单独选的**（「钉住」的意思是记住这个浏览器的选择，下一局自动带上），地块解锁和部署上限是**进程级**的（一开就是所有对局一起开，重启启动器回到关）。
- 只有当前等级能出现的干员/装备可选，且必须在卡池里还有份数。**自选编队**的干员例外，它们一直列着，等级没到的灰着，点它会说明还差几级。
- 倍速条在服务端还没打过补丁时不出现（和面板同一套判断），所以原版启动器下它不会亮在那里。
- 倍速是**自己这一整局**的节奏，包括 bot 的场次和 boss 回合；但它是按「现实 1 秒 = 游戏几秒」缩放，调太高时浏览器要在一帧里多跑几个 tick，机器吃力的话画面会掉帧（结果不受影响）。
- **直购和放入槽位共用一个每回合次数上限**（默认 3，面板可调，0 = 不限），**只算干员**：装备两条路都不占，额度用完了照样能买装备。干员用满后两条路都会被服务端拒绝。
- **过场等待只在单人局跟着倍速缩短**（见「倍速」一节）。同盟房间有两个以上真人时不动那三段，理由是不砍别人的决策时间。
- 沙盒「单位」那一栏是**按干员算的，不是按棋子**：同一个干员的复数张卡一起吃同一套改动（属性本来就挂在干员定义上，游戏里没有「只改这一颗棋子」的地方）。改完要看效果得**等下一场战斗**，已经开打的那场用的是开战前拷进单位里的那份数值。
- 面板的按钮、倍速条、自动倒转条初始位置都在屏幕右侧，**可以拖动**，位置存在浏览器 local storage 里；面板大小、列表画法（名字/立绘）、每回合上限、倍速和自动倒转的目标也存在那里，刷新页面后会补推给服务端。存下来的是**像素值**，对应那个窗口：换过窗口大小或屏幕之后，条会被**自动拉回可见范围**，面板也会**自动收进新视口**，而记住的值本身不动（回到大屏还是原来那个盒子）；拉不回来的（比如整条都在屏幕外）就点面板标题栏的**「复位」**，三条一起回到默认位置。
- **自选位那套配置是进程级的**（一份配置对整个服务端生效，不是每个座位一份），因为改到的是棋子定义本身，而定义不认座位。实际只有真人座位会带自选干员，所以日常用不出区别；两个真人同服且都用自造位子时，位子 id 一样就会共享同一份配置。
- **盟约的数值不按位子**（见「自选位」一节）：一条盟约只有一个记录，改了就落在场上每一个带它的干员身上。特质是按位子各一份的。
- **总开关管的是「从这一刻起」**：战斗已经开打的那一场，它装进去的策略、数值、地块解锁会打完这一场（下一场才干净）；沙盒策略叠起来时抬高的起手 LP 也收不回来，因为生命值已经花掉了，游戏里没有回收它的地方。
- 只影响你自己的**独立模拟**。同盟模拟（联机）也能用，但那是你自己的选择。
- **游戏目录记在 `mod.config.json` 的 `gameRoot`**。选过一次之后会写进去，下次直接用；`--game` 和拖到 `start.cmd` 上只对这一次生效，不写回。
- 手机那边的面板**字号跟着游戏的「设置 → 文字大小」走**，不是自己一套。所以如果你在手机上把游戏字号留成「小」，面板也跟着小（游戏自己也是小的）；调大之后两边一起变清楚。桌面上这一套的首屏大小跟以前完全一样。
- 手机 / 小窗口下，面板张开时「倍速 / 自动买卖 / 沙盒」三条悬浮条会被藏起来（面板铺得几乎满屏，它们原本会压在上面），关掉面板立刻回来。
- **安卓版在模拟器上验过，真机没验**：雷电 9（Android 9、x86_64，靠 ARM 翻译跑 arm64 的 libnode）上从安装到进对局面板可用，整条走通了；真手机上的触屏手感与性能还是没试过。
